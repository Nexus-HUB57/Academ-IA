## 🛠️ Workflow de Uso

### Para produzir 1 roteiro

1. **Escolher** roteiro deste índice.
2. **Copiar** template da persona (Ive / Alencar / Dupla).
3. **Validar** qualidade com [`../CHECKLIST_QUALIDADE.md`](../quality/CHECKLIST_QUALIDADE.md).
4. **Gerar TTS** (script em `../../videos/scripts/`).
5. **Gerar vídeo** com avatares (pipeline em [`../PIPELINE_PRODUCAO.md`](../PIPELINE_PRODUCAO.md)).
6. **Publicar** no YouTube (ver `../../youtube/publish_plan.csv`).

### Para revisar 1 roteiro

1. Pegar **versão canônica** deste índice.
2. Aplicar **checklist de qualidade**.
3. Se aprovado, copiar como `-roteiro-revisado.md`.
4. Atualizar este índice (mover para seção "revisados").
