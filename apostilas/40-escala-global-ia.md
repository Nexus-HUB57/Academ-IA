# Capítulo 4 — Anatomia de produto global-first

**Princípio:** projetar produto para ser **global desde o dia 1**, não adaptar depois.

**Checklist global-first:**

```
[ ] Textos externos (UI, marketing) em 100% i18n
[ ] Sem código hardcoded de idioma
[ ] Datas em ISO 8601
[ ] Moeda exibida, não assumida
[ ] Time zones em UTC, convertido no display
[ ] Números com locale (1.000 vs 1,000)
[ ] Imagens sem texto embutido
[ ] Vídeos legendados (auto-generated)
[ ] Customer support multilíngue
[ ] Documentação em 3+ idiomas
[ ] Compliance: LGPD + GDPR + CCPA
[ ] Payment em múltiplas moedas
[ ] Impostos: VAT, GST, sales tax
```

**Estrutura de arquivos:**

```
src/
├── i18n/
│   ├── en.json
│   ├── es.json
│   ├── pt-BR.json
│   ├── pt-PT.json
│   ├── fr.json
│   └── de.json
├── components/
│   └── (todos com t() function)
└── pages/
    └── (rotas com [locale] param)
```

**Plataformas i18n-friendly:**

- **Next.js** (i18n nativo)
- **Stripe** (multi-moeda nativa)
- **Notion** (multi-idioma via AI)
- **Webflow** (Localization)

# Capítulo 5 — Localização com IA (PT, EN, ES)

**Pipeline de localização com IA:**

```python
def localize_content(content, target_language):
    prompt = f"""
    Traduza e adapte o seguinte conteúdo de português brasileiro
    para {target_language}.
    
    Diretrizes:
    - Preserve o tom (acolhedor, técnico, motivacional)
    - Adapte expressões culturais (ex: 'saudade' → 'longing')
    - Use terminologia técnica correta do mercado-alvo
    - Mantenha exemplos relevantes ao mercado-alvo
    - Não traduzir marca/produto (ex: 'Nexus AffilIAte')
    
    Conteúdo original:
    {content}
    
    Tradução adaptada:
    """
    return llm.invoke(prompt, target_lang=target_language)
```

**Workflow de localização:**

```
Conteúdo original (PT-BR)
   ↓
IA gera tradução (EN, ES, FR, etc)
   ↓
Humano nativo revisa (1-2h por 10k palavras)
   ↓
Glossary check (termos técnicos)
   ↓
Tone of voice check (consistência)
   ↓
Publicação
```

# Capítulo 10 — Atendimento multilíngue com IA

### Arquitetura de atendimento 24/7 multilíngue

```
Cliente fala (qualquer idioma)
   ↓
STT (Whisper, suporta 99+ idiomas)
   ↓
Detecção de idioma + tradução
   ↓
LLM (Claude) responde no idioma original
   ↓
TTS (ElevenLabs) com voz no idioma
   ↓
Cliente ouve resposta nativa
```

### Implementação

```python
def support_agent(audio, customer_id):
    # 1. Transcrição (detecta idioma)
    transcript = whisper.transcribe(audio, detect_language=True)
    language = transcript.language  # "en", "es", "pt", etc
    
    # 2. Recupera contexto do cliente
    context = get_customer_context(customer_id)
    
    # 3. Gera resposta (no idioma detectado)
    response = llm.invoke(f"""
    Você é o suporte da Nexus Affil'IA'te.
    
    Idioma do cliente: {language}
    Contexto: {context}
    Mensagem: {transcript.text}
    
    Responda no mesmo idioma ({language}).
    Tom: profissional, prestativo, breve.
    Máximo 500 caracteres.
    """)
    
    # 4. Sintetiza voz no idioma
    voice_id = get_voice_id(language)
    audio_response = elevenlabs.synthesize(
        text=response,
        voice=voice_id,
        language=language
    )
    
    return audio_response, response  # retorna áudio + texto
```

**Custo por interação:**

- STT: $0.006/min
- LLM: $0.01/interação
- TTS: $0.01-0.05/interação
- **Total:** $0.03-0.07 por interação

**Comparação com humano:**

- Humano 24/7: US$ 5-15 por hora
- IA: US$ 0.03-0.07 por interação (mesmo equivalente)
- **IA é 100-500x mais barato**
