## 🛡️ Convenções

- **Numeração sequencial** (01-22) para onboarding.
- **Duração máxima** de 15 min para tutoriais numerados; até 60 min para "elaborados".
- **Pré-requisitos** declarados no frontmatter de cada tutorial.
- **Saída esperada** explícita (o que você deve ver/ter ao finalizar).

## 🛠️ Manutenção

Tutoriais são **atualizados frequentemente** conforme o produto evolui. Em caso de divergência entre tutorial e plataforma atual:

1. [Abrir issue no repo](https://github.com/Nexus-HUB57/Academ-IA/issues) com label `tutorial-desatualizado`.
2. Mencionar qual tutorial e a discrepância.
3. PR é bem-vindo com a correção.
