## 📋 Estrutura de Cada Curso

Cada curso possui **3 versões de material**:

| Arquivo | Conteúdo | Tamanho típico | Uso |
|---|---|---|---|
| `NN-nome-do-curso.md` | Material escrito (capítulos, exemplos, código) | 9-15KB | Leitura assíncrona, referência |
| `NN-nome-do-curso-slides.md` | Slides visuais (ASCII art) | 2-8KB | Apresentação em vídeo |
| `NN-nome-do-curso-roteiro.md` | Roteiro de narração (cenas + falas) | 4-22KB | Narração de vídeo-aula |

**Quando usar a versão estendida (Mavis)**:
- Videoaulas longas (> 90 min)
- Workshops e treinamentos presenciais
- Sessões de mentoria 1:1
- Quando o aluno pede aprofundamento específico

**Quando usar a versão padrão**:
- Videoaulas regulares (60-90 min)
- Onboarding rápido
- Referência para consulta

**Convenção**: os dois arquivos coexistem. Nunca sobrescrever um ao outro. Para "oficializar" a versão Mavis, o time de produção deve fazer uma PR de consolidação após review.
