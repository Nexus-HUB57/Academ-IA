## 🛡️ Regras de Uso

### Antes de usar um playbook

1. **Leia o frontmatter** — categoria, prioridade, owner.
2. **Verifique o contexto** — é mesmo este playbook?
3. **Confirme pré-requisitos** — checklist no início.
4. **Acompanhe SLA** — tempos definidos (resposta, ação, comunicação).

### Ao usar

1. **Documente** o incidente/uso em log.
2. **Siga os passos** sem pular (a menos que justificado).
3. **Comunique** stakeholders nos marcos definidos.
4. **Capture evidências** (logs, métricas, decisões).

### Depois

1. **Postmortem** se for crise.
2. **Feedback** ao owner do playbook.
3. **Sugira melhorias** via PR.
4. **Atualize** este índice se necessário.
